### C. Contradictions between reports

1. **Browser-first (HOSTING) vs server ensemble (SEGMENTATION).** BrowSeg can only run TotalSegmentator fold 0 for Apache tasks. CADS, VISTA3D, MOOSE, agreement QC, probability fusion and high-quality meshing cannot run in the browser on consumer hardware. Browser mode is therefore a **privacy-preserving "basic" tier**, not the "many-fold quality" product. Resolution: two tiers. (a) Local "quick" mode, TotalSegmentator `total` in the browser, nothing uploaded. (b) Opt-in server "full" mode with in-browser de-identification.
2. **VISTA3D licence:** SEGMENTATION says commercial-friendly, HOSTING says non-commercial. Resolved by L1: commercial use is allowed under the Open Model License with guardrail and Trustworthy AI conditions, and the model is research-only.
3. **Mesher:** HOSTING proposes "VTK flying-edges + Taubin + GLB Draco"; RENDERING proposes "SurfaceNets3D + windowed-sinc + meshopt". Adopt RENDERING's. Meshopt decodes faster, and Draco and meshopt cannot be combined on the same mesh.
4. **Viewer:** HOSTING proposes NiiVue/VTK.js; RENDERING proposes Cornerstone3D/OHIF plus three.js. The choice depends on the tier. NiiVue 1.0 is the lighter fit for the browser-only and mobile tier. Cornerstone3D is the fit for the clinical-research tier with DICOM-SEG. Don't build both in phase 1: start with NiiVue 1.0 or Cornerstone3D for the volume plus three.js for the meshes (see the stack).
5. **"Any body part" vs licences:** SEGMENTATION's primary model (TotalSegmentator Apache) lacks distal limbs, muscle/fat tissue and brain parcellation (L4). The fallback list puts the licence-gated `appendicular_bones` next to MOOSE. **Only MOOSE is legal for a possibly-commercial service.**
6. **Product purpose vs regulation:** the user's stated purpose ("post-diagnosis medical analysis") is a medical-device intended use (HOSTING §4). The audit and SEGMENTATION say "research-only". Every UI string, the domain name and the README must avoid clinical claims. That conflicts directly with the user's framing and needs an explicit decision.
7. **Privacy wording:** the current UI says "Your scan stays on this computer" (audit, ct.html:56). That is false for any server mode, and it must change before any hosting.
8. **Phone-home:** TotalSegmentator sends anonymous usage statistics by default (README l.364), and it downloads weights at runtime (l.194-198). HOSTING wants workers with "no outbound network". **Bake the weights into the image and set `send_usage_stats=false`, or jobs will fail or leak metadata.**

### D. Gaps no report covers adequately

| Gap | Required handling |
|---|---|
| Contrast vs non-contrast | Iodine changes vessel and organ HU. The models are trained on mixed phases (UNVERIFIED per class). `totalseg_get_body_stats` (licensed) is out. `totalseg_get_phase` is legacy and has no licence-key requirement stated (README l.189-191). Record the phase as metadata only, never as a gate. Do not reuse the classical bone threshold anywhere on contrast scans: the audit shows iodine at 150–400 HU passes the 150 HU low threshold. |
| Paediatric | No report gives validation evidence for children; TotalSegmentator and CADS training cohorts are mostly adults (UNVERIFIED). Detect it with the age tag before de-identification, or with body size. Show a "not validated for children" banner. Under DPDP, verifiable parental consent is needed for minors (HOSTING, UNVERIFIED). |
| Metal artefacts | The only open TotalSegmentator option is `hip_implant` (small-data, "less robust"). Keep the audit's metal detection and blooming-rim logic as a QC flag that masks unreliable regions. Do not mesh streak artefacts as anatomy. |
| Partial-body / limited FOV | TotalSegmentator `--statistics` zeroes structures that touch the border. The mesh cap at the scan edge (audit mesh.py:95) must be labelled "cut by scan edge" in the viewer, so a cut femur or liver isn't read as anatomy. Run region detection first and run only the relevant models (cost). |
| Slice thickness >3 mm | Models resample to 1.5 mm, but z-detail is gone, so meshes staircase and thin structures (vessels, ribs) break. Warn at >3 mm, mark structures thinner than 2× the slice as unreliable, and consider refusing above 5 mm (threshold is a suggestion). Never pick the thick series when a thin one exists (`choose_primary` already prefers the finest). |
| MR uploads | Route on the DICOM `Modality` tag. TotalSegmentator `total_mr` (50 classes, Apache) exists, but HU-based QC, the classical fallback and bone meshing from HU don't apply. Either support MR explicitly through `total_mr` with its own QC, or reject it with a clear message. CBCT (dental) has unreliable HU, so detect and warn. |
| Very large studies | Cap rows×cols×slices **before** allocating (audit: dicom.py:298 is uncapped). Resample above ~512²×1000 or 1 GB voxels. VISTA3D OOMs at 1024²×768, and the browser hits the 4 GiB WASM cap. Set per-job wall-clock and memory rlimits. |
| Formats | Compressed transfer syntaxes and Enhanced/multi-frame CT are unsupported by both the current code (audit) and BrowSeg. Decide on an allowlist. Decode compressed syntaxes server-side in a sandbox (codec CVE surface). |
| Gantry tilt | It is refused today. Resample to correct it instead (the audit suggests this). Otherwise many head CTs fail. |
| Pathology / post-op anatomy | The models segment *normal* anatomy. Tumours (except open `liver_lesions`, `lung_nodules`, and VISTA3D's 7 tumour classes), amputations, fractures, implants and situs anomalies will be mis-segmented. A "post-diagnosis" audience will expect lesions, so state this limit loudly. |
| Face re-identification | A head CT surface mesh is a recognisable face. TotalSegmentator `face` is licence-only (L5). Phase 1 needs a server-side policy: crop above the orbits, or never render skin for head scans. A commercial-safe defacing model is UNVERIFIED. |
| Failure UX | No report specifies it. Required pieces: per-stage status over SSE; plain-language refusal reasons (reuse the audit's ValueError layer); partial results, so every structure that passed QC ships even if others failed; a per-structure confidence badge from model agreement, volume range and border truncation; and a "report a problem" path that sends no image data. |
| Model/version provenance | The TotalSegmentator `--report` manifest plus the pinned HF revision (NV-Segment-CT sha) plus the CADS variant go into every result JSON. Reuse the existing `results.json` provenance pattern. |
| Validation | The current validation is self-consistency only (audit). Before launch, benchmark per structure (Dice and NSD) on public sets with compatible licences. The TotalSegmentator dataset is CC BY 4.0 (L9); the CADS dataset licence is UNVERIFIED. Publish the numbers. |

## 2. Risk table (public service)

| Risk | Likelihood / impact | Mitigation |
|---|---|---|
| **PHI breach.** Raw DICOM headers, burned-in names on scouts and dose screens, faces from head CT, guessable job URLs, or the existing `{"path":…}` arbitrary-read route | High / severe | Remove the `path` job and the localhost-only guard design. De-identify in the browser (PS3.15 Annex E) and drop non-axial series and secondary captures. Upload NIfTI only. Use unguessable IDs plus short-lived signed URLs. Encrypt with server-side encryption. TTL: uploads 24 h, results 7 days. Logs carry job ID only. Disable TotalSegmentator usage stats. Run workers with no egress. Pen-test before launch. Keep the audit's security tests as a regression suite. |
| **Regulatory.** "Post-diagnosis medical analysis" = SaMD (FDA LLZ Class II; EU MDR Rule 11 IIa/IIb; CDSCO A–D) | High / severe | Position as research and education only, with no clinical claims in the UI, domain, README or marketing. Click-through RUO terms. No integrations that feed care decisions. Begin the QMS, ISO 14971 and IEC 62304 groundwork only if a product path is chosen. Intended use is judged by all your claims, not by the disclaimer alone (HOSTING §4.2). |
| **Licence violation.** NC weights or the CADS default `reference` slip into production; NVIDIA guardrail clause; Trustworthy AI terms; CC BY-SA share-alike on derived weights | Medium / high | Use a weights allowlist in CI that checks hashes and licence: TotalSegmentator Apache tasks, MOOSE CC BY 4.0, CADS `open` CC BY-SA, NV-Segment-CT at a pinned revision. Hard-code `-license open`. Ship a NOTICE/attribution page. Get written confirmation from the MOOSE authors and from NVIDIA if commercial use is planned. Never deploy nnInteractive, VoxTell, NV-Segment-CTMR, MedSAM2, licensed TotalSegmentator tasks or MeshLib. |
| **Clinical misuse of wrong output.** Lungs labelled "fat" by the classical code, contrast labelled "bone", truncated organs, children, metal | High / high | Retire the classical segmenter from the default path. Add per-structure confidence (model agreement, volume range, mean-HU sanity, border truncation). Label meshes "cut by scan edge". Add banners for children, thick slices and metal. Show no measurements unless QC passes. |
| **Cost blow-up / DoS.** 6 GB uploads, 20 000 files, a multi-model ensemble on every job, no quotas | Medium / high | Cap uploads (e.g. 1 GB de-identified NIfTI) and voxel counts. Rate-limit per IP. Add a CAPTCHA (HOSTING). Run region-aware model selection: only the models whose region is in the FOV. Make CADS and VISTA optional in the "full" tier. Keep the browser tier at $0. Set budget alarms. Scale serverless to zero. |
| **Quality below the "many-fold" expectation** | Medium / high | SurfaceNets on fused probabilities, native-resolution meshing, no double decimation, shared colour and terminology (SlicerTotalSegmentator `.term.json`, Apache), a PBR three.js viewer, a volume and MPR view. Gate releases on `mesh_qc`, surface distance in mm and the public benchmark. |
| **Cross-border data law.** GDPR special category, DPDP | Medium / high | One stack per region (India first). DPIA. Browser tier avoids most processing. Consent screen. Erasure button with deletion receipts. |
| **Supply chain / codecs.** Untrusted DICOM through pydicom and compressed codecs; zip bombs | Medium / medium | Sandbox ingest (separate container, seccomp, rlimits). Transfer-syntax allowlist. Check the real decompressed size, not the declared one (audit flagged this as UNVERIFIED). No nested zips. |
| **Dependency churn.** NiiVue 0.x is archived 2027-01-15; MedSAM2 and STU-Net are stale | Medium / low | Target niivue/mono 1.0, or Cornerstone3D. Avoid stale models. |
| **Third-party browser instability.** Firefox WebGPU about 10× slower; Linux needs flags; iOS WebGL memory kills | High / low | Detect capability and fall back to the server tier or a demo gallery. Recommend Chrome or Edge in the UI. |

## 3. Final recommended stack

| Layer | Recommendation | Confidence |
|---|---|---|
| **Primary segmentation** | **TotalSegmentator v2 `total` (Apache) at 1.5 mm**, plus open subtasks chosen by detected region: `body`, `lung_vessels`, `vertebrae_pp_refined`, `craniofacial_structures`, `headneck_*`, `head_glands_cavities`, `trunk_cavities`, `liver_segments`. Weights baked into the image, `send_usage_stats=false`, `--report` manifest stored. | **High.** Licence verified from the README; most maintained. |
| **Limb, muscle and fat gap-filler** | **MOOSE 3.2** `clin_ct_peripheral_bones`, `clin_ct_muscles` and `clin_ct_body_composition` (CC BY 4.0 weights, Apache code), run only when limbs or the trunk wall are in the FOV. | **Medium.** The licence badge is verified, but Dice is unverified and per-site data terms need confirmation. |
| **Second opinion and extra structures** | **CADS `open` (CC BY-SA 4.0)**, pinned with `-license open`, used for agreement QC and head/neck extras. Optional "full" tier only. | **Medium-low.** The licence is verified; the performance of the `open` variant and its runtime are unverified. |
| **Interactive correction (phase 2)** | **VISTA3D / NV-Segment-CT** point-click, at a pinned HF revision, under the NVIDIA Open Model License. nnInteractive only in a strictly non-commercial deployment. | **Medium.** Licence verified, with guardrail and Trustworthy AI conditions; 16 GB GPU. |
| **Classical HU segmenter** | Retire from the default path. Keep it only as a test baseline, plus metal and artefact flagging. | High |
| **Fusion and QC** | Map to a canonical ontology (TotalSegmentator names plus SNOMED from the SlicerTotalSegmentator `.term.json`). Probability or priority fusion, hierarchy constraints, border-truncation flags, volume and HU sanity checks, inter-model Dice. Reuse `validate.py` and `mesh_qc`. | Medium-high |
| **Mesh pipeline** | VTK ≥ 9.5 `vtkSurfaceNets3D` (closed surface per label, constrained smoothing) on native-grid labels, with `vtkDiscreteFlyingEdges3D` + `vtkWindowedSincPolyDataFilter` as fallback. Then one decimation pass (meshoptimizer or `vtkQuadricDecimation`) to web and print levels of detail. trimesh and manifold3d for repair (no GPL in client bundles). QC in mm (HD95, mean surface distance, volume change). Export GLB through glTF-Transform (meshopt + quantisation, root node LPS→glTF ×0.001, SNOMED code, colour and affine in `extras`), plus STL, 3MF, NIfTI and DICOM-SEG (highdicom). | **High** for the components and licences; **medium** for the tuned smoothing defaults (VTK devs say they need tuning). |
| **Viewer** | Custom React shell: **three.js / React-Three-Fiber** for the PBR mesh view (GTAO, capped clipping, CT slice as a textured plane), plus **NiiVue 1.0 (niivue/mono)** for MPR, window/level and volume rendering in phase 1. Move to **Cornerstone3D** (MIT) when DICOM-SEG round-trip and clinical measurement matter (phase 2). Skip full OHIF in phase 1. | **Medium.** NiiVue 1.0 is still an RC, so track GA. |
| **Backend** | FastAPI (stateless) + tusd upload of de-identified NIfTI to S3-compatible storage (server-side encryption, lifecycle TTL) + Redis/Arq queue + containerised GPU worker (24 GB L4/A10G, one job at a time, rlimits and timeouts, no egress) + Postgres for job metadata + SSE for status. Ingest sandboxed with size caps and a transfer-syntax allowlist. Keep `dicom.py` geometry and tilt logic plus the security tests; replace `webapp.py` and `pipeline.py`. | **High** for the pattern; **low** for the cost figures (re-measure). |
| **Hosting mode** | **Phase 1:** a public research and education demo in one India region. Default "quick" tier runs TotalSegmentator `total` in the browser (BrowSeg, Apache), with no upload. Opt-in "full" tier does de-identification in the browser, then server inference on serverless GPU, with 24 h / 7 day deletion. Demo gallery built from the CC BY 4.0 TotalSegmentator dataset. No clinical claims. **Phase 2:** hospital partners on-premises or in a single-tenant region (MONAI Deploy or Kaapana; Kaapana is AGPL). | **Medium-high** for the posture; the regulatory and DPDP details are partly UNVERIFIED (see HOSTING §7). |

**Decision needed from the owner before building:** commercial or non-commercial intent, and acceptance of research-only positioning. This choice decides whether CADS `research` or nnInteractive can be used at all, and whether "post-diagnosis medical analysis" may appear anywhere in the product.
