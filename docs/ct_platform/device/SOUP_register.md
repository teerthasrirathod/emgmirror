# SOUP and licence register (index)

Research use, not for diagnosis or surgical planning, until licensed.

One register per software item, each kept with its own change history:

| Software item | Register | Maintained by |
|---|---|---|
| Segmentation engine (`src/emgmirror/ctseg`) | [SOUP_register_ctseg.md](SOUP_register_ctseg.md) | generated by `scripts/ctseg_soup_register.py` |
| Mesh pipeline (`src/emgmirror/ctmesh`) | [SOUP_register_ctmesh.md](SOUP_register_ctmesh.md) | edited by hand with each dependency change |
| Web viewer (`web/ct-viewer`) | see `web/ct-viewer/package.json` and its lockfile; a register is still to be written | - |

A component that appears in more than one register (for example VTK, pydicom, SimpleITK) must be pinned to the same version in each before a release build.
